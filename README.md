# Weather Analysis

From randomly generated data, this will show weather averages from that data.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download python
2. Download Pandas for python
3. Build in chosen IDE, I use VS Code

Instructions for using the software:

1. Ensure that weather_data.csv is clear
2. Select run on the generate_data.py file
3. Select run on the weather_analysis.py
